<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| service process -> Postgres | The running role's privileges decide whether RLS applies |
| migrator -> Postgres | A privileged connection that must never reach the service |
| test suite -> shared dev Postgres | A test touching deploy-postgres-1 could damage other apps' data |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-1-02-01 | Elevation of privilege | olive_app / RLS | mitigate | Roles NOSUPERUSER NOBYPASSRLS re-asserted by every bootstrap run; FORCE RLS on every table; fixture asserts rolsuper/rolbypassrls false and not owner member before any test runs |
