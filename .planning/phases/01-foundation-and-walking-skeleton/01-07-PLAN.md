<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| GitHub Actions runner -> repo | CI executes build and test code and downloads packages |
| developer workstation -> .env | Local secrets live in a gitignored file |
| README/.env.example -> developer behaviour | Documentation can steer a developer into an unsafe configuration |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-1-07-01 | Tampering | CI dependency resolution | mitigate | `--locked-mode` restore and a vulnerable-package gate that fails the job; permissions limited to `contents: read` |
| T-1-07-02 | Tampering | vendored vocabulary in CI | mitigate | `sha256sum -c` step before restore; test asserts the workflow hash equals the code constant |
| T-1-07-03 | Information disclosure | secrets committed via .env | mitigate | `.env` is gitignored (verified); `.env.example` carries only a visible placeholder password; `OLIVE_MIGRATOR_URL` is commented and the service refuses to start if it is set |
| T-1-07-04 | Elevation of privilege | migrator credential reaching the service | mitigate | README and `.env.example` direct the migrator URL to the shell only; startup guard (01-06) is the enforcement |
| T-1-07-05 | Tampering | unpinned third-party actions | accept | Only first-party `actions/checkout` and `actions/setup-dotnet` at major tags; no third-party actions; revisit SHA pinning with live write paths (not in this milestone) |
| T-1-07-06 | Denial of service | CI Testcontainers flakiness | accept | Single job; failures are visible; no shared infrastructure is touched by tests |
</threat_model>
