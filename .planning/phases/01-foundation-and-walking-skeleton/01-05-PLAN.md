| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-1-05-01 | Spoofing | authentication handler | mitigate | Introspect on every request first; inactive/unknown/expired/malformed all give identical 401 key_inactive; fail closed 503 on introspection error; IDN_01 tests including body-not-processed-first |
| T-1-05-02 | Elevation of privilege | principal checks | mitigate | agent-only plus allowlist enforced before validation; IDN_02 tests for user, application and non-allowlisted agent |
| T-1-05-03 | Information disclosure | cross-tenant GET | mitigate | tenant from key only; app predicate plus RLS (01-04); 404 identical to missing (D-11); API_02 tests |
| T-1-05-04 | Tampering | body-supplied tenant or nono_session_id | mitigate | Body tenant ignored; nono_session_id stored as advisory only; IDN_04 tests |
| T-1-05-05 | Information disclosure | session key / Authorization header in logs, responses, errors | mitigate | SessionKey redacts; no header logging, no HttpLogging, no developer exception page (builder forced to Production); exception handler logs type name only and returns static problems; API_01 error-path test greps responses and logs |
| T-1-05-06 | Denial of service | oversized or deeply nested JSON | mitigate | 1 MiB bounded read (413) and Kestrel MaxRequestBodySize, JsonDocument MaxDepth 64 (400) |

| T-1-05-08 | Information disclosure | Postgres error text in responses | mitigate | PostgresException maps to generic 500 internal_error; no Include Error Detail |
| T-1-05-09 | Repudiation | stored identity | mitigate | key_id, on_behalf_of, purpose, tenant_id, key_expires_at persisted with the proposal plus a submitted event (IDN-04) |
