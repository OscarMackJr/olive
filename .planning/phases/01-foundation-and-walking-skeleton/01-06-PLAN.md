## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| process environment/.env -> service config | Misconfiguration (missing environment, migrator URL present) crosses here |
| DI container -> request pipeline | A stub registered in production would replace real identity |
| service -> Postgres | A privileged connection would bypass RLS |
| service -> log sinks/error pages | Secrets could leave through logs or exception pages |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-1-06-01 | Spoofing | INonProductionOnly stub in production | mitigate | Descriptor scan plus resolved-instance check (catches factory registrations) in an IStartupFilter before listen; FND_05 tests incl. instance, factory and type registrations and a positive control |
| T-1-06-02 | Elevation of privilege | superuser/BYPASSRLS/owner connection | mitigate | DatabaseSafetyChecks codes at startup; DB_07 tests for each role class; fixture asserts the same for olive_app |
| T-1-06-03 | Tampering | vendored vocabulary | mitigate | SHA-256 of raw bytes at startup against the constant, copied (not embedded) so runtime tamper is detected; CI and FND_03 test compare the constant with VENDORED.md |
| T-1-06-04 | Elevation of privilege | migrator credentials in the service | mitigate | Service refuses to start if OLIVE_MIGRATOR_URL exists in configuration or .env; only the Migrator reads it |
| T-1-06-05 | Information disclosure | session key in logs, headers, responses, exceptions | mitigate | SENTINEL tests on success, inactive and hostile-exception paths; framework exception logging suppressed, handler logs type names only; developer exception page never enabled |
| T-1-06-06 | Information disclosure | guard failure messages | mitigate | Static messages with rule codes only; tests assert no URL, user, password or configured value appears |
| T-1-06-07 | Tampering | schema/version drift | mitigate | Embedded migration list must equal schema_migrations exactly (behind, ahead, checksum); the service refuses to start otherwise |
| T-1-06-08 | Denial of service | startup guard bypass in tests only | accept | WebApplicationFactory uses the same filter (no test-only bypass exists); OLIVE_ENVIRONMENT=ci is a valid, guarded value |
