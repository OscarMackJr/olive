## Phase Goal

ROADMAP Phase 6 goal (not yet in user-story form): An approved proposal executes exactly once in simulation, and the whole core-value chain can be queried from the execution record.

Output: Application ports and ExecutionService, SimulatedActionExecutor, CatalogExecutionCheck, and their unit tests.
</objective>

| Executor to filesystem | The JSONL file stands in for the target system |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-06 | Information Disclosure | JSONL line | mitigate | ExecutionRequest record has no secret fields; Utf8JsonWriter field-by-field allow-list; unit test asserts exact property set (D-10) |
| T-06-07 | Information Disclosure | failure reasons | mitigate | Reasons are constants; ExecutionService never reads exception messages; grep gate in acceptance criteria (D-09) |
| T-06-08 | Tampering | double target write | mitigate | Service never calls executor when a finished or started row exists (D-08); unit-tested |
