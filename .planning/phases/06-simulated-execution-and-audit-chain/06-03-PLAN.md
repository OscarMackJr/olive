## Phase Goal

ROADMAP Phase 6 goal (not yet in user-story form): An approved proposal executes exactly once in simulation, and the whole core-value chain can be queried from the execution record.

This is the first end-to-end slice: a reviewer approves, and the proposal is executed in simulation, visible as state, ledger rows and one JSONL line.

<objective>
Implement the Postgres execution store with the lock-holder transaction, register the executor stack in the host, add the output-path startup guard, and hook execution into the decision endpoint after the approve commit.

Purpose: D-01, D-02, D-11, D-12 and D-13 turn the Plan 02 core into a working approve-then-execute path.
Output: ExecutionSql, PostgresExecutionStore, TenantUnitOfWork lock-holder, host wiring, guard, endpoint hook, factory change, end-to-end tests.
</objective>

## Trust Boundaries

|----------|-------------|

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-11 | Tampering | double execution via concurrent approve | mitigate | Advisory lock held on connection A across the attempt plus unique (tenant_id, proposal_id, phase); replay test asserts one JSONL line |
| T-06-12 | Elevation of Privilege | execution inside approve transaction | mitigate | Hook runs after DecideAsync returns, on fresh connections; reject triggers nothing (D-01) |
| T-06-13 | Information Disclosure | logs and responses on execution fault | mitigate | Static log message only; hook swallows exception text; decide response shape asserted unchanged (D-09) |
| T-06-14 | Denial of Service | stuck lock holder | mitigate | Lock timeout returns null (LockTimeout result), test with 1 s timeout |
| T-06-15 | Tampering | misconfigured output path | mitigate | CheckExecutorOutput fails startup; static message omits the path (D-11) |
| T-06-16 | Tampering | client disconnect mid-execution | mitigate | CancellationToken.None for the execution call |
| T-06-SC | Tampering | package installs | accept | No package installs in this plan |
</threat_model>
