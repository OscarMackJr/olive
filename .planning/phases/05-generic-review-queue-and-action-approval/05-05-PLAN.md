<objective>
Give a named, authenticated dev reviewer a hard-separated API to list and read their tenant's open review items: the DevReviewer authentication scheme, the Q13 tenant resolution, the caller-separation matrix, the queue application service, and the GET list and get endpoints.

Purpose: all later reviewer actions (payload, claim, decide) ride on this scheme and service. Because multi-scheme ASP.NET challenge behaviour is the least certain part of the phase, the four-case caller matrix is proven here first. Slice: a reviewer with a header lists the alpha tenant's items; an agent key or a missing header cannot.
Output: reviewer fixtures with schema, identity source, claims, handler, AgentKey changes, service, DTOs, endpoints, guard check, tests.
</objective>
