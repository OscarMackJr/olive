| Olive to identity directory (port) | Read-only lookup; no session key or token crosses it |
| requester claim to reviewer identity | on_behalf_of is a client-supplied string; only oid+tid equality decides self-approval |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-15 | Elevation of Privilege | self-approval by on_behalf_of user | mitigate | ApprovalIdentityCheck compares resolved oid+tid; UPN never compared; lookalike and same-oid tests |
| T-05-16 | Elevation of Privilege | ambiguous or missing mapping treated as pass | mitigate | NotFound/Ambiguous/Malformed/Unavailable all map to refusing verdicts; unit tests per outcome (fail closed) |
| T-05-17 | Denial of Service / Elevation | resolver hang or exception | mitigate | linked-token timeout and catch-all to Unavailable; never a 500 or fail-open |
| T-05-18 | Spoofing | fixture identity source in production | mitigate | INonProductionOnly on FixtureUserIdentityResolver; FND-05 guard refuses production start |
| T-05-19 | Information Disclosure | oids/UPNs in logs or verdict text | mitigate | verdicts carry only static causes and type names; no logging in check or verifier |
