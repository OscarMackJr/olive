<objective>
A claimant reviewer holding the required role approves or rejects an action proposal with a rationale. The queue item and the proposal move together in one transaction, self-approval and unresolved identities are refused (approve only), repeats are no-ops, conflicts and expired proposals are distinct stable errors, and every outcome is auditable.

Purpose: this is the approval decision the program's core value hinges on (named reviewer, rationale, not the requester, before execution in Phase 6). Slice: a reviewer claims, decides over HTTP, and the proposal reaches approved or rejected with a recorded auth source.
Output: store DecideAsync, service orchestration, decision route and DTOs, reasons, store-level and HTTP tests.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| reviewer request body to decision | Only decision and rationale are accepted; identity, tenant and auth source come from the authenticated claim |
| Olive to identity resolver | Read-only, fail-closed lookup used only to refuse self-approval |
| decision transaction | Item and proposal must change together |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-37 | Elevation of Privilege | self-approval | mitigate | approve-only oid+tid check via ApprovalIdentityCheck; fail closed on unresolved/ambiguous/unavailable (APR-02, D-06) |
| T-05-38 | Elevation of Privilege | non-claimant or role-less decision | mitigate | claimant check under row lock + DB CHECK decided_by = claimed_by; registry-driven role gate at decide (Q8, D-09) |
| T-05-39 | Tampering | item/proposal divergence | mitigate | single (conn, tx); CAS miss throws and rolls back; forced-miss test (APR-04) |
| T-05-40 | Tampering | duplicate or conflicting decisions | mitigate | lock-then-classify; AlreadyDecidedSame/Conflict; concurrent double-submit test (QUE-08) |
| T-05-41 | Tampering | approving an expired proposal | mitigate | lazy expiry in the same transaction with committed 409 (POL-08, D-11) |
| T-05-42 | Spoofing | caller-supplied decided_by / auth_source / tenant | mitigate | body allowlist rejects extra members; values taken from claims (APR-05) |
| T-05-43 | Information Disclosure | rationale echo in logs, events, problems | mitigate | rationale stored once on the item row only; static problem titles; sentinel tests |
| T-05-44 | Denial of Service | resolver hang | mitigate | UserIdentityVerifier timeout and catch-all to Unavailable -> 503 |
