<objective>
First end-to-end slice: an agent submits a proposal whose fixture trace matches, and Olive verifies it through the popeye token stub and the fixture resolver before storing it as verified, recording `trace_verification = fixture` and `trace_schema_version`, readable through GET.

Purpose: after this plan a real caller can do something new (get a trace-verified proposal), and every later slice (refusals, fail-closed, containment) rides on this wiring. Non-Verified verdicts are mapped by a single fail-closed 503 `trace_verification_unavailable` arm in this plan (nothing stored); plans 04 and 05 replace that arm with the refusal and the 422/503 mappings.
Output: committed fixture contract, Hometown fixture resolver, Popeye token stub, Host wiring, endpoint step, test harness auto-fixture mode.
</objective>
