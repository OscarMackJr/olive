## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Olive -> popeye issuer | The only boundary that receives the session key |
| Olive -> hometown resolver | Receives only the service token grant, returns untrusted facts |
| Resolver response -> verifier | Untrusted data compared against Olive-derived values |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-06 | Spoofing | TraceVerifier check 4 | mitigate | compare facts.AgentId to grant.DelegatedAgentId (popeye-derived), null counts as mismatch |
| T-03-07 | Tampering | TraceVerifier check 5 | mitigate | ordinal compare to caller-supplied Jcs.ProposalHash; null or differing hash refused; verifier never mutates or re-hashes |
| T-03-08 | Elevation of privilege | ServiceTokenProvider | mitigate | claims re-validated vs introspection on miss and on hit; cache key includes key_id; expiry = min(token, key) minus skew; over-long token rejected uncached |
| T-03-09 | Information disclosure | ServiceTokenGrant / SessionKey | mitigate | sealed class with redacting ToString and DebuggerDisplay; ITraceResolver signature cannot accept SessionKey; Application has no logging |
| T-03-10 | Denial of service | caches | mitigate | 10,000-entry cap with clear-on-full for both caches; correctness never depends on cache |
| T-03-11 | Denial of service | resolver hang | mitigate | linked CTS with 5 s default timeout, mapped to Unavailable (fail closed) |
| T-03-12 | Tampering | not-found turned permanent | mitigate | NotFound and all failures never cached (TRC-08), verdict NotFound is not a refusal |
| T-03-SC | Tampering | package installs | accept | no new packages in this plan (research Package Legitimacy Audit: none) |
