## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Item page -> IdP redirect | decision draft leaves the page's request |
| IdP -> callback | fresh token proves recent authentication |
| resume URL -> DraftStore | opaque key presented by a browser |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-26 | Elevation of Privilege | Stale role used to approve after removal | mitigate | auth_time window (5 min cap, missing = stale) forces prompt=login + max_age=0; fresh token's roles are what DecideAsync sees; mock test with role-absent scenario |
| T-07-27 | Spoofing | Silent SSO token treated as re-authentication (Entra may ignore max_age) | mitigate | OnTokenValidated requires auth_time >= challenge time - 60 s; absent or stale evidence fails closed; live Entra check is a manual UAT item in plan 06 |
| T-07-28 | Information Disclosure | Rationale in URL, logs or TempData | mitigate | server-side DraftStore, opaque 256-bit key only in URL, redacting snapshot, sentinel scan over URLs/HTML/logs |
| T-07-29 | Tampering | Draft replay or hijack across users | mitigate | single use, oid- and item-bound, 10 min TTL, capped size; wrong-oid test |
| T-07-30 | Tampering | State-changing GET after IdP round trip | mitigate | resume GET only restores form; decide requires a new antiforgery POST; test asserts unchanged state |
| T-07-31 | Elevation of Privilege | Re-auth extends the 8 h absolute cap or switches identity | mitigate | original olive:session_start preserved; different oid rejected |
