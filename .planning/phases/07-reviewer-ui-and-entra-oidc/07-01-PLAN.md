<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser -> Razor Pages | cookie, form fields, returnUrl are untrusted |
| cookie -> ReviewerContext | tenant claim must only come from the server-side map |
| default AgentKey scheme -> non-agent routes | agent keys must not be introspected outside agent routes |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-01 | Spoofing | /dev/sign-in picker | mitigate | DevSignInGate is INonProductionOnly so FND-05 refuses production start; page returns 404 without the gate; picker takes only a fixture id and re-resolves identity and tenant server-side |
| T-07-02 | Tampering | CSRF on picker and sign-out POSTs | mitigate | Razor Pages antiforgery default (no IgnoreAntiforgeryToken); `__Host-olive-af` cookie; SameSite Lax session cookie; test asserts 400 without token |
| T-07-03 | Spoofing | Open redirect via returnUrl | mitigate | accept only `Url.IsLocalUrl`, else `/review`; test with `//evil.example` |
| T-07-04 | Elevation of Privilege | Session lives past absolute cap through sliding renewal | mitigate | OnValidatePrincipal enforces olive:session_start + 8 h with injected TimeProvider; ManualTimeProvider test |
| T-07-05 | Information Disclosure | 403 page and flash echo input | mitigate | only static reason codes and copy; FlashMessages returns null for unknown codes |
| T-07-06 | Elevation of Privilege | Agent key or cookie accepted on wrong route group | mitigate | AgentKey handler NoResult outside /v1/proposals and /v1/catalog; cookie scheme named only in ReviewerUi policy; full matrix in plan 06 |
| T-07-07 | Information Disclosure | XSS via item data | mitigate | Razor encoding, no Html.Raw, CSP default-src 'self' without unsafe-inline, grep gate in acceptance criteria |
</threat_model>
